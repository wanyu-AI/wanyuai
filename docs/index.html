为什么用它

把「客户端」和「服务端」都握在自己手里，而不是被某个账号绑定。

多模型接入

兼容 OpenAI、Anthropic、Google 等主流接口，填自己的 Key 就能用；也内置官方转发模型，按积分计费。

Agent 工作区

基于 proot 的轻量 Linux 环境，无需 root；AI 可在手机里执行命令、整理文件、跑脚本。

MCP 工具协议

接入 Model Context Protocol，搜索、文件、数据库等能力按需挂载，不必改客户端。

完整 Markdown

代码高亮、LaTeX 公式、表格、Mermaid 流程图都能渲染，回答可以直接当笔记用。

对话分支

同一条消息可以分叉出不同走向，来回比较不丢上下文，适合写方案和调 prompt。

默认不上云

对话与设置只存本机；云端同步是开关项，默认关闭，换设备或退出登录都不会自动上传。

自己部署一套

仓库里是完整三件套：安卓端、PHP 后端、管理后台，加一份建表脚本。

android/Kotlin + Compose 客户端，Gradle 多模块
backend/PHP 8.1+ 接口：认证 / 支付 / 同步 / AI 转发 / 风控
admin/PHP 管理后台：用户、积分、风控、版本、邮件
database/schema.sql，建表与初始配置
docs/DEPLOY.md / API.md / INTEGRATION.md
部署文档 接口文档
上线前必改三处：后端 config.php 的数据库与支付密钥；客户端 WanyuConfig.kt 的域名与 API_SIGN_KEY；以及换成自己的签名证书。仓库里都是占位值，直接部署是跑不通的。
